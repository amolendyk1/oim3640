# milestone 0 - My project proposal 
What am I building: 
- I am building a Flask based app that takes an app or place name and I use API to get cordinates to return all the nearest MBTA stops. In addition, it says if it is wheelchair accessible.

- Why I chose this:
  - I chose this to help me naviage the city better since I do not live there currently. In addition, it could be used for all places which can help when I travel.
  
- Core features: 
  - A function that returns longitude and latitude
  - A function that tells if the stops are wheelchair accessible
  - A function that returns all the stops within a radius
  - A map that shows a pin for each stop

What I don't Know yet:
- I do not know how to embed a Mapbox map, handle errors, a feature where users can choose a radius.
